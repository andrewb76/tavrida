# Переход с phpBB на Markdown

Если вы привыкли к кнопкам `[b]`, `[i]`, `[url]` — здесь всё устроено иначе, но проще. Разберём по пунктам, что во что превращается.

---

## Главное отличие

В phpBB вы **оборачивали текст в теги**: `[b]жирный[/b]`.
В Markdown вы **обрамляете текст символами**: `**жирный**`.

Логика одна, но запись короче и читается «как есть» — даже без обработки видно, что текст выделен.

---

## Таблица соответствий

| phpBB | Markdown | Результат |
|---|---|---|
| `[b]текст[/b]` | `**текст**` | **жирный** |
| `[i]текст[/i]` | `*текст*` | *курсив* |
| `[u]текст[/u]` | нет прямого аналога | подчёркивание в MD не поддерживается |
| `[s]текст[/s]` | `~~текст~~` | ~~зачёркнутый~~ |
| `[url]адрес[/url]` | `<адрес>` или просто адрес | ссылка |
| `[url=адрес]текст[/url]` | `[текст](адрес)` | [текст](адрес) |
| `[img]адрес[/img]` | `![описание](адрес)` | картинка |
| `[quote]текст[/quote]` | `> текст` | цитата |
| `[code]код[/code]` | `` `код` `` или блок в трёх кавычках | моноширинный |
| `[list][*]пункт[/list]` | `* пункт` | список |
| `[color=red]текст[/color]` | нет аналога | цвет в MD не поддерживается |
| `[size=20]текст[/size]` | нет аналога | размер шрифта не поддерживается |
| `[center]текст[/center]` | нет аналога | центрирование не поддерживается |

---

## Практические примеры «до и после»

### Пример 1. Простое сообщение

**Было (phpBB):**
```
[quote="Иван"]Отличная монета![/quote]
Согласен. Вот её [url=https://example.com]каталожная ссылка[/url].
```

**Стало (Markdown):**
```
> Отличная монета!

Согласен. Вот её [каталожная ссылка](https://example.com).
```

---

### Пример 2. Список с картинками

**Было (phpBB):**
```
[list]
[*][b]Аверс[/b] — [img]https://example.com/av.jpg[/img]
[*][b]Реверс[/b] — [img]https://example.com/rv.jpg[/img]
[/list]
```

**Стало (Markdown):**
```
* **Аверс** — ![аверс](https://example.com/av.jpg)
* **Реверс** — ![реверс](https://example.com/rv.jpg)
```

---

### Пример 3. Цитата с ответом

**Было (phpBB):**
```
[quote="Пётр"][b]Вопрос:[/b] какая проба?[/quote]
Отвечаю: 84-я золотниковая.
```

**Стало (Markdown):**
```
> **Вопрос:** какая проба?

Отвечаю: 84-я золотниковая.
```

---

## Что делать с тем, чего нет в Markdown

Иногда форум разрешает вставлять сырой HTML прямо в Markdown. Если действительно нужно **подчеркнуть** или **выровнять по центру** — попробуйте:

```
<u>подчёркнутый текст</u>
<p align="center">текст по центру</p>
```

Но часто это **запрещено** администрацией форума. Тогда просто откажитесь от этих украшений: они не несут смысла, а текст без них читается чище.

---

## Шпаргалка на память

Запомните всего три правила — и 90% сообщений вы напишете без подсказок:

1. **Две звёздочки** — жирный. **Одна** — курсив.
2. **Квадратные скобки + круглые** — ссылка. **С восклицательным знаком** — картинка.
3. **Знак `>` в начале строки** — цитата. **Знак `*` в начале строки** — список.

Всё остальное — детали, которые придут с опытом.
