## 5. Справочная таблица: базовый синтаксис Markdown

Компактная шпаргалка для быстрого доступа. Все примеры даны в «сыром» виде — так, как их нужно набирать.

| Элемент | Синтаксис | Результат |
|---|---|---|
| **Заголовок 1** | `# Текст` | Крупный заголовок |
| **Заголовок 2** | `## Текст` | Заголовок поменьше |
| **Заголовок 3** | `### Текст` | Ещё меньше |
| **Жирный** | `**текст**` | **текст** |
| **Курсив** | `*текст*` | *текст* |
| **Жирный курсив** | `***текст***` | ***текст*** |
| **Зачёркнутый** | `~~текст~~` | ~~текст~~ |
| **Маркированный список** | `* пункт` или `- пункт` | • пункт |
| **Нумерованный список** | `1. пункт` | 1. пункт |
| **Ссылка** | `[текст](url)` | [текст](url) |
| **Картинка** | `![alt](url)` | Картинка |
| **Цитата** | `> текст` | Блок цитаты |
| **Код в строке** | `` `код` `` | `код` |
| **Блок кода** | ```` ```язык ... ``` ```` | Блок кода |
| **Горизонтальная линия** | `---` | Линия |
| **Таблица** | `\| A \| B \|` + `\|---\|---\|` | Таблица |
| **Сноска** | `текст[^1]` + `[^1]: пояснение` | Сноска |
| **Чекбокс** | `- [x] готово` | ✅ готово |
| **Экранирование** | `\*звёздочка\*` | *звёздочка* |
| **Перенос строки** | Два пробела + Enter | Новая строка в том же абзаце |
| **Разрыв абзаца** | Пустая строка между абзацами | Новый абзац |

## 6. Справочная таблица: расширенный синтаксис

| Элемент | Синтаксис | Примечание |
|---|---|---|
| **Таблица с выравниванием** | `\|:---\|:---:\|---:\|` | Лево / Центр / Право |
| **Блок кода с подсветкой** | ```` ```python ... ``` ```` | Поддерживаемые языки: python, js, bash, json, sql, yaml, html, css |
| **Сноска** | `[^1]` | Требует определения `[^1]: текст` в конце документа |
| **Список задач** | `- [x]` / `- [ ]` | Поддерживается в GFM |
| **Ссылка-сноска** | `[текст][id]` + `[id]: url` | Удобно для повторяющихся ссылок |
| **HTML внутри MD** | `<details>`, `<summary>`, `<br>`, `<sub>`, `<sup>`, `<kbd>` | Зависит от парсера форума |
| **Математика (LaTeX)** | `$формула$` или `$$формула$$` | Поддерживается на GitHub, в Obsidian |
| **Диаграммы Mermaid** | ```` ```mermaid ... ``` ```` | Поддерживается на GitHub, GitLab |
| **Автоссылка** | `<https://example.com>` | Ссылка, даже если внутри спецсимволы |
| **Вложенный список** | Отступ 2–4 пробела | `* пункт` → `  * подпункт` |

## 7. Справочная таблица: переход с phpBB на Markdown

| phpBB | Markdown | Результат |
|---|---|---|
| `[b]текст[/b]` | `**текст**` | **жирный** |
| `[i]текст[/i]` | `*текст*` | *курсив* |
| `[u]текст[/u]` | — | Не поддерживается |
| `[s]текст[/s]` | `~~текст~~` | ~~зачёркнутый~~ |
| `[url]адрес[/url]` | `<адрес>` | Ссылка |
| `[url=адрес]текст[/url]` | `[текст](адрес)` | [текст](адрес) |
| `[img]адрес[/img]` | `![описание](адрес)` | Картинка |
| `[quote]текст[/quote]` | `> текст` | Цитата |
| `[code]код[/code]` | `` `код` `` | Моноширинный |
| `[list][*]пункт[/list]` | `* пункт` | Список |
| `[color=red]текст[/color]` | — | Не поддерживается |
| `[size=20]текст[/size]` | — | Не поддерживается |
| `[center]текст[/center]` | — | Не поддерживается |
