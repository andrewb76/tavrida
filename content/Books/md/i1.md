# Markdown для начинающих

## Что это такое

Markdown — это способ форматировать текст **прямо во время набора**, используя простые символы. Никаких кнопок «жирный/курсив» — вы просто ставите звёздочки и решётки, а форум сам превращает их в красивое оформление.

Правило одно: **символ форматирования — пробел — текст — символ форматирования**.

---

## Заголовки

Ставьте решётку `#` в начале строки. Чем больше решёток — тем меньше заголовок.

```
# Заголовок 1 (самый крупный)
## Заголовок 2
### Заголовок 3
```

---

## Жирный, курсив, зачёркнутый

```
**жирный текст**
*курсив*
***жирный курсив***
~~зачёркнутый~~
```

Отобразится так: **жирный**, *курсив*, ***жирный курсив***, ~~зачёркнутый~~.

---

## Списки

**Маркированный** — звёздочка или дефис + пробел:

```
* Первый пункт
* Второй пункт
  * Подпункт (отступ в 2 пробела)
```

**Нумерованный** — цифра с точкой:

```
1. Первый
2. Второй
3. Третий
```

---

## Ссылки

```
[Текст ссылки](https://example.com)
```

Отобразится как: [Текст ссылки](https://example.com)

Если хотите, чтобы ссылка была видна целиком — просто вставьте URL:

```
https://example.com
```

---

## Картинки

```
![Описание](https://example.com/image.jpg)
```

Восклицательный знак перед `[` — обязателен. Внутри квадратных скобок — описание (появится, если картинка не загрузится).

---

## Цитата

Поставьте `>` в начале строки:

```
> Это цитата. Часто используется для выделения мысли
> или ответа на чужое сообщение.
```

Отобразится так:

> Это цитата.

---

## Код и моноширинный текст

Обратные кавычки `` ` `` — для коротких фрагментов внутри строки:

```
Используйте команду `sudo apt update` в терминале.
```

Для блока кода — три обратных кавычки в начале и в конце:

# Markdown для начинающих

## Разделитель

Три дефиса на отдельной строке:

```
---
```

---

## Перенос строки

Обычный Enter в Markdown **не** создаёт новый абзац. Чтобы начать новую строку:

* Оставьте **пустую строку** между абзацами.
* Или поставьте **два пробела** в конце строки и нажмите Enter.

---

## Чего НЕ надо делать

* Не расставляйте пробелы внутри `**жирного **` — звёздочки должны прилипать к тексту.
* Не забывайте пробел после `#`, `*`, `>`, `1.` — без него Markdown не сработает.
* Не бойтесь экспериментировать — просто нажмите «Предпросмотр».
